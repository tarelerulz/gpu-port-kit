`jfk.pcm`: the 11 s sample `jfk.wav` from the whisper.cpp repository (MIT), a 1961 speech by US President Kennedy (a US government work), stored as raw 16 kHz mono 16-bit little-endian PCM.
`jfk.txt`: its transcript as produced by the Oido CPU build (`tasr_cli_a72`, nemo8, greedy CTC) and by the GPU path in this kit. The GPU path must give the same text.
